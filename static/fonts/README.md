# Source Sans 3

Unmodified Adobe Source Sans 3 variable TrueType fonts, version 3.052.
Downloaded from the Adobe `source-sans` repository's `release/VF` directory:

- https://github.com/adobe-fonts/source-sans/blob/release/VF/SourceSans3VF-Upright.ttf
- https://github.com/adobe-fonts/source-sans/blob/release/VF/SourceSans3VF-Italic.ttf

The upright file is named SourceSans3-Regular.ttf locally; both files retain
their variable weight axis. OFL.md contains the redistribution license.
Fonts are served locally by the app. No runtime network request is required.
