                Zotero → Obsidian note sync
                
    When Zotero is authoritative is off, the Library → Zotero Notes Sync tab compares each Zotero reading note against the Obsidian note exported from it, per note and per direction: [take Zotero's] rewrites only the marked Zotero region of your note (frontmatter, tags and header stay byte-for-byte; undo from Settings → History and Restore), [keep mine] writes your region to the Zotero note through the web API (undo from Tagging → Restore), and [merge…] lets you edit a three-way merge for both notes, with separate destination results. Images and content outside the comparable region require review. A write that would delete words the other side added asks a second, explicit time after you have read the diff. Missing notes can be created from the same tab (vault note → Settings → History and Restore; Zotero note → Tagging → Restore, which trashes it).
    
                
    
                    
                    
                    On, the Zotero Notes Sync tab hides [keep mine] and [merge…] and offers [mirror from Zotero] — create the missing notes, rewrite every marked region that differs from Zotero (whatever it held), record sync points — with [refresh all from Zotero] kept as the narrower rewrite-only sweep. Rewrites are not journalled: every note they replace must be committed in the vault's git, which is the undo; creations are journalled and need no git. Notes deleted in Zotero are listed, never removed.

                Restore-journal retention
                
    Every tag write is journalled so it can be undone. Finder and Zotero operations keep their previous tags inside the record — there is no separate snapshot file — so they are never trimmed automatically and the journal grows for the life of the library. Turning retention on permanently deletes the undo for operations past your threshold. Note history is never affected. See the current size under Library → Tagging → Restore…, which also offers a one-off Compact.
